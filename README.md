# Hugging Bay Homebrew tap

    brew install barneywohl/hbay/hbay

`hbay` — the Hugging Bay supply-chain CLI: verify, lock, restore, adopt, dedup store, eval, doctor, capsule. Requires Node 20+. Release artifacts (tarball, checksums, CycloneDX SBOM, provenance, signed manifest) are served from https://huggingbay.xyz/dl/.
